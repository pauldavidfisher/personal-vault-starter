# Fetched Texts

This folder contains texts saved via the "Fetch a URL" feature.

Paste any URL into the Fetch box in the sidebar — Personal Vault will pull the full text, index it for search, and let you save it permanently to your vault.

Good sources to try:
- https://www.gutenberg.org — 70,000+ free books
- https://ccel.org — Christian classics
- https://standardebooks.org — beautifully formatted classics
- https://en.wikisource.org — historical documents

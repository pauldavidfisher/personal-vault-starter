# Welcome to Personal Vault

A local personal library — fetch texts, clip passages, search everything.

## Try it out

**Search** — type any word or phrase above. Try "manners", "restless", "memory", or "time".

**Folders** — click any folder in the sidebar to browse as a card grid.

**Clips** — click "All clips" to see saved highlights from these texts.

**Fetch** — paste any URL from Project Gutenberg or Wikipedia to add a text permanently.

## What's in this demo

This vault contains a curated selection of classic texts and notes:

- **fetched/** — Chesterton, Augustine, Marcus Aurelius, Burke
- **essays/** — notes on reading and commonplace books
- **quotes/** — selected passages from each author

All texts are public domain, sourced from Project Gutenberg and CCEL.
